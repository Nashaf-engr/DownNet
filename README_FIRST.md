# ⭐ READ THIS FIRST - DownNet Setup Guide

**Welcome to DownNet!** Your complete social media downloader is ready to use.

---

## ⏱️ Time Required

- **Setup**: 5 minutes
- **First download**: 1 minute
- **Total**: ~6 minutes to working application

---

## 🚀 Fastest Start (Choose One)

### Option A: Automated Setup (Recommended)

**Windows - Copy & Paste This:**
```bash
cd H:\DownNet
setup.bat
```

**Linux/macOS - Copy & Paste This:**
```bash
cd H:\DownNet
chmod +x setup.sh && ./setup.sh
```

### Option B: Docker (Single Command)

```bash
cd H:\DownNet
docker-compose up --build
```

Automatically opens at: http://localhost:3000

### Option C: Manual Setup

See [QUICKSTART.md](QUICKSTART.md)

---

## ▶️ After Setup: Start the App

**Terminal 1 (Backend):**
```bash
cd H:\DownNet\backend
# Windows
venv\Scripts\activate
# Linux/macOS
source venv/bin/activate

python app.py
```

**Terminal 2 (Frontend):**
```bash
cd H:\DownNet\frontend
npm start
```

**Open Browser:**
```
http://localhost:3000
```

That's it! 🎉
