## 🚀 HOW TO GET STARTED

### Fastest Way (3 minutes)

**Windows:**
```bash
cd H:\DownNet
setup.bat
# Then in terminal 1: cd backend && venv\Scripts\activate && python app.py
# Then in terminal 2: cd frontend && npm start
# Open: http://localhost:3000
```

**Linux/macOS:**
```bash
cd H:\DownNet
chmod +x setup.sh && ./setup.sh
# Then in terminal 1: cd backend && source venv/bin/activate && python app.py
# Then in terminal 2: cd frontend && npm start
# Open: http://localhost:3000
```

### Docker Way (1 command)

```bash
cd H:\DownNet
docker-compose up --build
# Open: http://localhost:3000
```
